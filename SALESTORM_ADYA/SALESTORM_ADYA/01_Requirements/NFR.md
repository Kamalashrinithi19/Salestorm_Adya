# Non-Functional Requirements

| Area | Requirement |
|---|---|
| Consistency | Inventory correctness takes priority at the reservation boundary. |
| Scalability | Admission control, Kafka partitioning and horizontal service scaling. |
| Availability | Multi-AZ deployment and stateless replicas. |
| Reliability | Idempotency, retries, circuit breakers, outbox and reconciliation. |
| Security | WAF, TLS, JWT, authorization, rate limiting and secrets protection. |
| Observability | Metrics, logs, tracing, correlation IDs and alerts. |
